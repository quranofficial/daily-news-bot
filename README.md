# daily-news-bot — بۆتی ڤیدیۆی قورئان 🌙

بۆتی تێلەگرام بۆ دروستکردنی ڤیدیۆی قورئانی پیرۆز بە دەنگی قاریەکان،
تەفسیری ئاسان، پاشبنەمای وێنە/ڤیدیۆ، و ڕێکخستنی تەواو بۆ هەر بەکارهێنەرێک.

## تایبەتمەندیەکان

- 🎙️ هەڵبژاردنی قاری لە لیستی قاریەکان (reciters.json)
- 📖 هەڵبژاردنی سوورەت و مەودای ئایەتەکان
- 🖼️ پاشبنەما: **١٠ وێنە + ١٠ ڤیدیۆ** (١.png..١٠.png / ١.mp4..١٠.mp4)، ڕسم، ڤیدیۆی بەردەوام
  (لە نێوان ئایەتەکاندا restart نابێت)، گەلەری مۆبایل، یان ڕەش
- 🎲 **دیزاینی هەڕەمەکی (Random)**: یەک دوگمە — ڕەنگ، قەبارە، شوێن، فۆنت، **ئەنیمەیشن**، تاریکی و
  پاشبنەما هەموویان بە شێوەیەکی جوان بە هەڕەمەکی دەگۆڕدرێن؛ هەر جارێک دیزاینیەکی تازە
- 🎨 ڕێکخستنی دەق: ڕەنگ، قەبارە، شوێن — لەگەڵ **پێشبینینی زیندوو** دوای هەر گۆڕانکارییەک
- ✨ **٣ جۆر ئەنیمەیشنی نووسین** بۆ ئایەت و تەفسیر (لە مینیوی ڕێکخستنەکان):
  - ✨ **فەیدی نەرم (fade)** — نووسینەکە بە نەرمی و بەرەبەرە دەردەکەوێت
  - ⬆️ **سەرکەوتن (rise)** — نووسینەکە لە خوارەوەوە بەرز دەبێتەوە و دەردەکەوێت
  - 🔍 **زووم (zoom)** — نووسینی ئایەت بە نەرمی دەگەڕێتەوە شوێنی خۆی
  - تەفسیرەکە بە چرکەیەکی بچووک دوای ئایەتەکە دێت، بۆ جوانی زیاتر
- 🌟 **سێبەری نەرم لەژێر هەموو نووسینەکاندا** — نووسینەکە لەسەر هەر پاشبنەمایەک خوێندنەوەی ئاسان هەیە
- 🌄 **پاشبنەمای جوانکراو**: ڕەنگی زیندووتر (saturation)، تاریکی نەرمی قەراغەکان (vignette)،
  و پاشبنەمای وێنە بە هێواشی «دەهێنێت» (Ken Burns zoom) — لە نێوان ئایەتەکاندا restart نابێت
- 🔤 **فۆنتی قورئان**: قورئان ١ / قورئان ٢ / قورئان ٣ — یان **خۆت فۆنت هەڵبژێرە**
  (بەکارهێنەر فایلی فۆنتی TTF/OTF لە مۆبایلی خۆی بار دەکات)
- ✍️ **شێوەی نووسین (تەفسیر)**: شێوەی ١ / شێوەی ٢ / شێوەی ٣ — یان **خۆت فۆنت هەڵبژێرە**
- 👁️ **ناوی سوورەت و ژمارەی ئایەت**: یەک دوگمەی نیشاندان/شاردنەوە + یەک دوگمەی شوێن (سەرەوە ⬆️ / خوارەوە ⬇️)
- 📝 **دەقی خوارەوە (Footer)**: دوگمەی نیشاندان/شاردنەوە — دەتوانیت لایبەریت و بیهێنیتەوە
  وەکو ناوی سوورەت، هەروەها دەقەکەی بگۆڕیت
- ⏳ **پێشکەوتنی داواکاری** (progress bar) لە کاتی دروستکردنی ڤیدیۆ
- 👥 **هاوکاری هاوکات**: ٤-٥ بەکارهێنەر دەتوانن بە یەک کات داواکاری بکەن (`MAX_CONCURRENT_JOBS`)
- 🔒 پشکنینی ئەندامێتی کەناڵ

## دامەزراندن

```bash
# 1) پێداویستیەکان
pip install -r requirements.txt

# 2) FFmpeg (پێویستە)
sudo apt install ffmpeg

# 3) تۆکینی بۆت
export BOT_TOKEN="123456:ABC-DEF..."   # لە @BotFather

# 4) کارپێکردن
python botyuser.py
```

### ژینگە ئارەزوومەندانەکان (اختیاری)

| variable | بنەڕەت | وەسف |
|----------|--------|------|
| `MAX_CONCURRENT_JOBS` | `5` | ژمارەی ڤیدیۆی هاوکات کە بە یەک کات دروست دەکرێن |

## فۆنتەکان

هەموو فۆنتەکان لەناو فۆڵدەری **`fonts/`** دان و بەکارهێنەر لە ڕێکخستنەکان
هەڵیان دەبژێرێت:

| key | فایل | ناو لە بۆتەکە | بەکاردێت بۆ |
|-----|------|----------------|--------------|
| `quran1` | `fonts/quran1.ttf` | قورئان ١ | دەقی ئایەت |
| `quran2` | `fonts/quran2.ttf` | قورئان ٢ | دەقی ئایەت |
| `quran3` | `fonts/quran3.ttf` | قورئان ٣ | دەقی ئایەت |
| `rabar1` | `fonts/rabar1.ttf` | شێوەی ١ | تەفسیر و نووسین |
| `rabar2` | `fonts/rabar2.ttf` | شێوەی ٢ | تەفسیر و نووسین |
| `rabar3` | `fonts/rabar3.ttf` | شێوەی ٣ | تەفسیر و نووسین |

- **خۆت فۆنت هەڵبژێرە** 📤: لە مینیوی فۆنتەکان دوگمەی «خۆت فۆنت هەڵبژێرە» دابگرە و
  فایلی فۆنتەکەت (TTF یان OTF) وەک فایل بنێرە. بۆتەکە پیتە کوردیەکان (ڕ ڵ ۆ ێ ە...)
  پشکنین دەکات و فۆنتەکە تەنها بۆ هەمان بەکارهێنەر هەڵدەگیرێت.
- ئەگەر فایلێکی فۆنت لەسەر سێرڤەر نەبوو، بۆتەکە خۆی لە GitHub دایدەزێنێت
  (`fonts/quran1.ttf` ... لەسەر branch ـی main).
- دەتوانیت فۆنتەکان بە فۆنتی خۆت بگۆڕیت: تەنها فایلەکان لە فۆڵدەری `fonts/`
  بە هەمان ناو (quran1.ttf, rabar1.ttf...) نوێ بکەرەوە.

## ڕێکخستنی ناوی سوورەت

لە مینیوی ڕێکخستنەکان دوو دوگمە هەیە:

- 👁️ **ناوی سوورەت و ژمارەی ئایەت**: ✅ نیشان دەدرێت / ❌ شاراوەتەوە
- 📍 **شوێنی ناوی سوورەت**: ⬆️ سەرەوە / ⬇️ خوارەوە

ناوی سوورەت وەک خۆی لە داتابەیسەکە دەنووسرێت (بۆ نموونە: **سورەتی الفاتحة**) —
پێشگرێکی زیادە لەسەر ڤیدیۆکە نییە.

## ئەنیمەیشنی نووسین

لە مینیوی ڕێکخستنەکان دوگمەی **✨ ئەنیمەیشنی نووسین** هەڵبژێرە — سێ جۆر هەیە و
هەڵبژاردنەکە بۆ هەر بەکارهێنەرێک پاشەکەوت دەکرێت:

| جۆر | چۆنێتی |
|-----|--------|
| ✨ فەیدی نەرم (fade) | ئایەتەکە بە نەرمی دەردەکەوێت، پاشان تەفسیرەکە |
| ⬆️ سەرکەوتن (rise) | نووسینەکان لە خوارەوەوە بە جوڵەیەکی نەرم بەرز دەبنەوە |
| 🔍 زووم (zoom) | ئایەتەکە بە چوێوەیەکی کەم گەورەیە و بە نەرمی دەگەڕێتەوە شوێنی خۆی |

> تێبینی: ئەنیمەیشنەکە لە پێشبینینی وێنەدا نایەت — تەنها لە ڤیدیۆدا دەردەکەوێت.

## پێکهاتەی فایلەکان

- `botyuser.py` — بۆتی سەرەکی (polling، مینیوەکان، دروستکردنی ڤیدیۆ + ئەنیمەیشنەکان، progress، فۆنتی تایبەت)
- `quran_video.py` — وێنەکانی دەقی ئایەت (٢ لایەری جیاواز: ئایەت + تەفسیر) + سیستەمی فۆنتەکان
- `reciters.json` — لیستی قاریەکان
- `fonts/` — فۆڵدەری فۆنتەکان (quran1-3.ttf و rabar1-3.ttf)
- `*.db` — داتابەیسی کاتی ئایەتەکان بۆ هەر قارییەک
- `*.png`, `*.mp4` — پاشبنەماکان

> تێبینی: `bot.py` و `.github/workflows/main.yml` (ناردنی شەوانە بۆ کەناڵ)
> سڕاونەتەوە — ئێستا بۆتەکە تەنها وەڵام ئەو کەسە دەداتەوە کە داواکاری دەکات.
