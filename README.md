# daily-news-bot — بۆتی ڤیدیۆی قورئان 🌙

بۆتی تێلەگرام بۆ دروستکردنی ڤیدیۆی قورئانی پیرۆز بە دەنگی قاریەکان،
تەفسیری ئاسان، پاشبنەمای وێنە، و ڕێکخستنی تەواو بۆ هەر بەکارهێنەرێک.

## تایبەتمەندیەکان

- 🎙️ هەڵبژاردنی قاری لە لیستی قاریەکان (reciters.json)
- 📖 هەڵبژاردنی سوورەت و مەودای ئایەتەکان
- 🚀 **دوگمەی دەستپێکردن**: مینیووی تێلەگرام (دوگمەی شین) فەرمانەکانی تێدایە، و هەموو نامەکانی
  ڕێنمایی دوگمەی «🚀 دەستپێکردن» و «ℹ️ ڕێنمایی» یان لەسەر — بەکارهێنەر پێویست ناکات /start بنووسێت
- 🖼️ پاشبنەما: **١٠ وێنە** (١.png..١٠.png)، گەلەری مۆبایل، یان ڕەش
  *(پاشبنەمای ڤیدیۆ لابراوە — لە جیاتی وێنەکان بە جوڵەی نەرمی Ken Burns دەهێنرێن،
  لە نێوان ئایەتەکاندا restart نابێت)*
- 🎲 **دیزاینی هەڕەمەکی (Random)**: یەک دوگمە — ڕەنگ، قەبارە، شوێن، فۆنت، **ئەنیمەیشن**، تاریکی و
  پاشبنەما هەموویان بە شێوەیەکی جوان بە هەڕەمەکی دەگۆڕدرێن؛ هەر جارێک دیزاینیەکی تازە
- 🎨 ڕێکخستنی دەق: ڕەنگ، قەبارە، شوێن — لەگەڵ **پێشبینینی زیندوو** دوای هەر گۆڕانکارییەک
- ✨ **٥ جۆر ئەنیمەیشنی نووسین** بۆ ئایەت و تەفسیر (لە مینیوی ڕێکخستنەکان):
  - ✨ **فەیدی نەرم (fade)** — نووسینەکە بە نەرمی و بەرەبەرە دەردەکەوێت
  - ⬆️ **سەرکەوتن (rise)** — نووسینەکە لە خوارەوەوە بەرز دەبێتەوە و دەردەکەوێت
  - 🔍 **زووم (zoom)** — نووسینی ئایەت بە نەرمی دەگەڕێتەوە شوێنی خۆی
  - ➡️ **خاڵێوە لە ڕاستەوە (slide)** — نووسینەکە لە لای ڕاستەوە خاڵێوە دەکەوێتە ناوەوە
  - ⬇️ **دابەزین لە سەرەوە (drop)** — نووسینەکە لە سەرەوەوە بە نەرمی دادەبەزێت
  - تەفسیرەکە بە چرکەیەکی بچووک دوای ئایەتەکە دێت، بۆ جوانی زیاتر
- 🎯 **یاسای ئەنیمەیشن**: ئایەت و تەفسیر **هەمیشە** ئەنیمەیشنیان لەسەرە؛ بەڵام
  «قورئانی پیرۆز - ڕێگای ئیسلام» و ناوی سوورەت و ژمارەی ئایەت **تەنها لە یەکەم
  ئایەتدا** ئەنیمەیشنیان لەسەرە — دواتر بێ جوڵە دەمێننەوە تا کۆتایی ڤیدیۆ
- 📏 **قەبارەی ڤیدیۆ بۆ هەر پلاتفۆرمێک** (پێش دروستکردن هەڵدەبژێردرێت):

  | پلاتفۆرم | دۆمێنسیۆن | تێبینی |
  |----------|-----------|--------|
  | 📘 Facebook | 1080×1920 | |
  | 🎵 TikTok | 1080×1920 | کوالیتی بەرزتر |
  | 📸 Instagram | 1080×1920 | کوالیتی بەرزتر |
  | ✈️ Telegram | 720×1280 | خێرا و سووک — هەرگیز سنووری 50MB تێناپەڕێت |
  | 📱 گەلەری | 1080×1920 | بەرزترین کوالیتی (CRF 18) |

  هەڵبژاردەی کۆتایی بۆ هەر بەکارهێنەرێک پاشەکەوت دەکرێت و بە ✔ نیشان دەدرێت.
  ئەگەر ڤیدیۆکە لە 50MB گەورەتر بوو، بۆتەکە خۆی وەشانێکی بچووککراوە دەنێرێت
  و دەڵێت قەبارەی ڕەسەن چەند بووە (هەڵەی 413 چیتر ڕوو نادات).
- 🌟 **سێبەری نەرم لەژێر هەموو نووسینەکاندا** — نووسینەکە لەسەر هەر پاشبنەمایەک خوێندنەوەی ئاسان هەیە
- 🌄 **پاشبنەمای جوانکراو**: ڕەنگی زیندووتر (saturation)، تاریکی نەرمی قەراغەکان (vignette)،
  و پاشبنەمای وێنە بە هێواشی «دەهێنێت» (Ken Burns zoom) — لە نێوان ئایەتەکاندا restart نابێت
- 🔤 **فۆنتی قورئان**: قورئان ١ / قورئان ٢ / قورئان ٣ — یان **خۆت فۆنت هەڵبژێرە**
  (بەکارهێنەر فایلی فۆنتی TTF/OTF لە مۆبایلی خۆی بار دەکات)
- ✍️ **شێوەی نووسین (تەفسیر)**: شێوەی ١ / شێوەی ٢ / شێوەی ٣ — یان **خۆت فۆنت هەڵبژێرە**
- 👁️ **ناوی سوورەت و ژمارەی ئایەت**: یەک دوگمەی نیشاندان/شاردنەوە + یەک دوگمەی شوێن (سەرەوە ⬆️ / خوارەوە ⬇️)
- 📝 **دەقی خوارەوە (Footer)**: دوگمەی نیشاندان/شاردنەوە — دەتوانیت لایبەریت و بیهێنیتەوە
  وەکو ناوی سوورەت، هەروەها دەقەکەی بگۆڕیت
- ⏳ **پێشکەوتنی داواکاری** (progress bar) لە کاتی دروستکردنی ڤیدیۆ
- ⚡ **خێرایی بەرز**: پاشبنەمای وێنە یەک جار ئامادە دەکرێت (scale + ڕەنگ + vignette)
  و هەموو بەشەکان دووبارە بەکاری دەهێننەوە؛ ڕێندەرکردن لە 720×1280 دەکرێت و
  قەبارە گەورەکان بە یەک پاسی کۆتایی (Lanczos) بۆ 1080×1920 دەگەیەندرێن
- 👥 **هاوکاری هاوکات**: ٢ بەکارهێنەر دەتوانن بە یەک کات داواکاری بکەن (`MAX_CONCURRENT_JOBS`)
- 🔒 پشکنینی ئەندامێتی کەناڵ

## دامەزراندن

```bash
# 1) پێداویستیەکان
pip install -r requirements.txt

# 2) FFmpeg (پێویستە)
sudo apt install ffmpeg

# 3) تۆکینی بۆت
export BOT_TOKEN="123456:ABC-DEF..."   # لە @BotFather

# 4) کارپێکردن
python botyuser.py
```

### ژینگە ئارەزوومەندانەکان (اختیاری)

| variable | بنەڕەت | وەسف |
|----------|--------|------|
| `MAX_CONCURRENT_JOBS` | `2` | ژمارەی ڤیدیۆی هاوکات کە بە یەک کات دروست دەکرێن |

## فۆنتەکان

هەموو فۆنتەکان لەناو فۆڵدەری **`fonts/`** دان و بەکارهێنەر لە ڕێکخستنەکان
هەڵیان دەبژێرێت:

| key | فایل | ناو لە بۆتەکە | بەکاردێت بۆ |
|-----|------|----------------|--------------|
| `quran1` | `fonts/quran1.ttf` | قورئان ١ | دەقی ئایەت |
| `quran2` | `fonts/quran2.ttf` | قورئان ٢ | دەقی ئایەت |
| `quran3` | `fonts/quran3.ttf` | قورئان ٣ | دەقی ئایەت |
| `rabar1` | `fonts/rabar1.ttf` | شێوەی ١ | تەفسیر و نووسین |
| `rabar2` | `fonts/rabar2.ttf` | شێوەی ٢ | تەفسیر و نووسین |
| `rabar3` | `fonts/rabar3.ttf` | شێوەی ٣ | تەفسیر و نووسین |

- **خۆت فۆنت هەڵبژێرە** 📤: لە مینیوی فۆنتەکان دوگمەی «خۆت فۆنت هەڵبژێرە» دابگرە و
  فایلی فۆنتەکەت (TTF یان OTF) وەک فایل بنێرە. بۆتەکە پیتە کوردیەکان (ڕ ڵ ۆ ێ ە...)
  پشکنین دەکات و فۆنتەکە تەنها بۆ هەمان بەکارهێنەر هەڵدەگیرێت.
- ئەگەر فایلێکی فۆنت لەسەر سێرڤەر نەبوو، بۆتەکە خۆی لە GitHub دایدەزێنێت
  (`fonts/quran1.ttf` ... لەسەر branch ـی main).
- دەتوانیت فۆنتەکان بە فۆنتی خۆت بگۆڕیت: تەنها فایلەکان لە فۆڵدەری `fonts/`
  بە هەمان ناو (quran1.ttf, rabar1.ttf...) نوێ بکەرەوە.

## ڕێکخستنی ناوی سوورەت

لە مینیوی ڕێکخستنەکان دوو دوگمە هەیە:

- 👁️ **ناوی سوورەت و ژمارەی ئایەت**: ✅ نیشان دەدرێت / ❌ شاراوەتەوە
- 📍 **شوێنی ناوی سوورەت**: ⬆️ سەرەوە / ⬇️ خوارەوە

ناوی سوورەت وەک خۆی لە داتابەیسەکە دەنووسرێت (بۆ نموونە: **سورەتی الفاتحة**) —
پێشگرێکی زیادە لەسەر ڤیدیۆکە نییە.

## ئەنیمەیشنی نووسین

لە مینیوی ڕێکخستنەکان دوگمەی **✨ ئەنیمەیشنی نووسین** هەڵبژێرە — پێنج جۆر هەیە و
هەڵبژاردنەکە بۆ هەر بەکارهێنەرێک پاشەکەوت دەکرێت:

| جۆر | چۆنێتی |
|-----|--------|
| ✨ فەیدی نەرم (fade) | ئایەتەکە بە نەرمی دەردەکەوێت، پاشان تەفسیرەکە |
| ⬆️ سەرکەوتن (rise) | نووسینەکان لە خوارەوەوە بە جوڵەیەکی نەرم بەرز دەبنەوە |
| 🔍 زووم (zoom) | ئایەتەکە بە چوێوەیەکی کەم گەورەیە و بە نەرمی دەگەڕێتەوە شوێنی خۆی |
| ➡️ خاڵێوە لە ڕاستەوە (slide) | نووسینەکان لە لای ڕاستەوە دەچنە ناوەوە (گونجاوە بۆ دەقی ڕاست بۆ چەپ) |
| ⬇️ دابەزین لە سەرەوە (drop) | نووسینەکان لە سەرەوەوە بە نەرمی دادەبەزن |

**یاسای ئەنیمەیشن بۆ لایەنەکان:**

- **ئایەت + تەفسیر**: لە هەموو ئایەتێکدا ئەنیمەیشن دەکرێن (ئایەت سەرەتا، تەفسیر 0.15 چرکە دواتر)
- **دەقی خوارەوە + ناوی سوورەت + ژمارەی ئایەت**: تەنها لە **یەکەم ئایەتدا** بە نەرمی
  دەردەکەون؛ لە ئایەتەکانی دواتردا بێ جوڵەن (تەنها ژمارەی ئایەت نوێ دەبێتەوە)

> تێبینی: ئەنیمەیشنەکە لە پێشبینینی وێنەدا نایەت — تەنها لە ڤیدیۆدا دەردەکەوێت.

## قەبارەی ڤیدیۆ و سنووری تێلەگرام

بۆتەکە پێش دروستکردنی ڤیدیۆ دەپرسێت: **«قەبارەی ڤیدیۆکە چۆن بێت؟»** —
Facebook / TikTok / Instagram / Telegram / گەلەری.

- هەموو قەبارەکان چوارچێوەی تەواوی 9:16 هەڵدەگرن — هیچ دەقێک ناپچڕێت
- بەشەکان بە خێرایی لە 720×1280 ڕێندەر دەکرێن، پاشان قەبارە گەورەکان بە
  یەک پاسی Lanczos بۆ 1080×1920 دەگەیەندرێن
- **سنووری تێلەگرام**: بۆت ناتوانێت زیاتر لە 50MB بارکات (هەڵەی HTTP 413).
  بۆتەکە bitrate بە پێی ماوەی ڤیدیۆکە دادەنێت و ئەگەر پێویست بوو
  خۆکارانە وەشانی بچووککراوە دەنێرێت و بەکارهێنەر دەئاگاھێنێتەوە

## پێکهاتەی فایلەکان

- `botyuser.py` — بۆتی سەرەکی (polling، مینیوەکان، دروستکردنی ڤیدیۆ + ئەنیمەیشنەکان، progress، فۆنتی تایبەت)
- `quran_video.py` — وێنەکانی دەقی ئایەت (٣ لایەری جیاواز: زانیاری + ئایەت + تەفسیر) + سیستەمی فۆنتەکان
- `reciters.json` — لیستی قاریەکان
- `fonts/` — فۆڵدەری فۆنتەکان (quran1-3.ttf و rabar1-3.ttf)
- `*.db` — داتابەیسی کاتی ئایەتەکان بۆ هەر قارییەک
- `*.png` — پاشبنەماکان (وێنە)

## GitHub Actions

- **📅 Daily Quran Ayah** (`.github/workflows/main.yml`): ڕۆژانە کاتژمێر ٢١ی بەغدا —
  ئایەت و تەفسیر دەنێرێت بۆ کەناڵ (`bot.py`، لەگەڵ preflight check و retry بۆ هەڵەی 403)
- **🎬 Quran User Bot** (`.github/workflows/botyuser.yml`): بۆتەکە بە شێوەی **24/7** کار دەکات —
  سیستەمەکە لە دوو بەش پێکهاتووە:
  ١. **Self-chaining handover**: هەر نموونەیەکی بۆت لە ٥ کاتژمێر و ٢٠ خولەکدا نموونەی داهاتوو
  dispatch دەکات، ڤیدیۆکانی ناوەڕاست تەواو دەکات (drain) و پاشان بە ئارامی دەچێتە دەرەوە.
  ٢. **Watchdog**: هەر ١٥ خولەک جارێک دەپشکنێت ئایا ڕەنێکی بۆتەکە کاردەکات یان نا —
  ئەگەر نەبوو، یەکێکی نوێ دەست پێ دەکات (ئەگەر زنجیرەکە بپچڕێت، دوای حەد ئەقەل ١٥ خولەک
  بۆتەکە دەگەڕێتەوە).
  *(بۆ چالاککردنی تەواوی handover ەکە، workflow ەکە پێویستە `GH_TOKEN` و
  `permissions: contents: write, actions: write` هەبن — فایلە ئامادەکراوەکە لە
  وەشانێکی نوێدا بەردەستە.)*
