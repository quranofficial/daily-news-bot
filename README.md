# daily-news-bot — بۆتی ڤیدیۆی قورئان 🌙

بۆتی تێلەگرام بۆ دروستکردنی ڤیدیۆی قورئانی پیرۆز بە دەنگی قاریەکان،
تەفسیری ئاسان، پاشبنەمای وێنە/ڤیدیۆ، و ڕێکخستنی تەواو بۆ هەر بەکارهێنەرێک.

## تایبەتمەندیەکان

- 🎙️ هەڵبژاردنی قاری لە لیستی قاریەکان (reciters.json)
- 📖 هەڵبژاردنی سوورەت و مەودای ئایەتەکان
- 🖼️ پاشبنەما: ڕسم، ڤیدیۆی بەردەوام (لە نێوان ئایەتەکاندا restart نابێت)، یان ڕەش
- 🎨 ڕێکخستنی دەق: ڕەنگ، قەبارە، شوێن — لەگەڵ **پێشبینینی زیندوو** دوای هەر گۆڕانکارییەک
- 🔤 **٣ فۆنت** (قورئانی، ڕەبار، ئەمیری) — بەکارهێنەر خۆی فۆنت هەڵدەبژێرێت
- ⏳ **پێشکەوتنی داواکاری** (progress bar) لە کاتی دروستکردنی ڤیدیۆ
- 👥 **هاوکاری هاوکات**: ٤-٥ بەکارهێنەر دەتوانن بە یەک کات داواکاری بکەن (`MAX_CONCURRENT_JOBS`)
- 🔒 پشکنینی ئەندامێتی کەناڵ

## دامەزراندن

```bash
# 1) پێداویستیەکان
pip install -r requirements.txt

# 2) FFmpeg (پێویستە)
sudo apt install ffmpeg

# 3) تۆکینی بۆت
export BOT_TOKEN="123456:ABC-DEF..."   # لە @BotFather

# 4) کارپێکردن
python botyuser.py
```

### ژینگە ئارەزوومەندانەکان (اختیاری)

| variable | بنەڕەت | وەسف |
|----------|--------|------|
| `MAX_CONCURRENT_JOBS` | `5` | ژمارەی ڤیدیۆی هاوکات کە بە یەک کات دروست دەکرێن |

## فۆنتەکان

سێ فۆنت لە فۆڵدەری بۆتەکەدان و بەکارهێنەر لە ڕێکخستنەکان هەڵیان دەبژێرێت:

| key | فایل | ناو |
|-----|------|-----|
| `quran` | `quran.ttf` | قورئانی (بنەڕەت بۆ ئایەت) |
| `rabar` | `rabartafsir.ttf` | ڕەبار (بنەڕەت بۆ تەفسیر) |
| `amiri` | `Amiri-Regular.ttf` | ئەمیری |

ئەگەر فایلێکی فۆنت نەبوو، بۆتەکە خۆی لە GitHub دایدەزێنێت.

## پێکهاتەی فایلەکان

- `botyuser.py` — بۆتی سەرەکی (polling، مینیوەکان، دروستکردنی ڤیدیۆ، progress)
- `quran_video.py` — وێنەکانی دەقی ئایەت + فۆنتەکان
- `reciters.json` — لیستی قاریەکان
- `quran.ttf`, `rabartafsir.ttf`, `Amiri-Regular.ttf` — فۆنتەکان
- `*.db` — داتابەیسی کاتی ئایەتەکان بۆ هەر قارییەک
- `*.png`, `*.mp4` — پاشبنەماکان
- `.github/workflows/botyuser.yml` — کارپێکردنی بۆتەکە لە GitHub Actions (هەر کاتژمێرێک ڕیسێت)

> تێبینی: workflow ـی کۆنی `main.yml` (ناردنی شەوانە بۆ کەناڵ) لەگەڵ `bot.py` سڕاونەتەوە —
> ئێستا بۆتەکە تەنها وەڵام ئەو کەسە دەداتەوە کە داواکاری دەکات.
